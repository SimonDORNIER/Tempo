# Tempo Health

Application Android personnelle santé / récupération / entraînement.

## Version 0.6.0

Cette version personnalise réellement les séances proposées :

- durée disponible configurable : 10, 15, 20 ou 30 minutes ;
- matériel disponible : tapis et chaise ;
- exercices favoris ;
- exercices à éviter ;
- nouveaux exercices avec et sans matériel ;
- générateur qui respecte les exercices exclus ;
- favoris remontés en priorité dans les séances compatibles ;
- durée de séance ajustée automatiquement au temps disponible ;
- récupération rouge/orange pouvant raccourcir la séance malgré une durée cible plus longue ;
- historique, groupes travaillés et difficulté ressentie toujours pris en compte ;
- paramètres mémorisés localement sans compte ni serveur.

Package Android : `fr.tempo.health`.
TempoSave reste indépendant sous `fr.tempo.sport`.
